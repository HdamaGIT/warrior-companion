# M1 verification: probe

**Goal:** the probe loads, writes `WarriorWorkshopProbeDB`, and the full test script in `docs/PROBE_RESULTS.md` has been run **before the beta closes on 21 Oct 2026**.
**Prerequisite:** the `WarriorWorkshopProbe` junction exists (`docs/DEV_SETUP.md` §2), and the game was restarted after creating it.

| # | Step | Expected result | Pass? |
|---|---|---|---|
| 1 | AddOns list at character select. | **Warrior Workshop Probe** is listed and enabled. | |
| 2 | Enter the world with `/console scriptErrors 1` on. | No Lua errors. | |
| 3 | `/wwprobe` | Four or five lines: version/build/interface, API found/missing counts, `issecretvalue: <type>`, event registration counts, "Saved to WarriorWorkshopProbeDB…". | |
| 4 | `/wwprobe help` | Lists eight commands. | |
| 5 | Open Blacksmithing, then `/wwprobe prof`. | "Profession dump: N recipe IDs, 10 dumped in full." (or a clear "No recipe IDs" message). | |
| 6 | `/wwprobe gear` | "Gear dump saved: 19 slots, N equipment set(s)." | |
| 7 | `/wwprobe item` + shift-click an item | "Item dump #1 saved." (if it says "not cached", run it again). | |
| 8 | `/wwprobe ping` while solo | "Ping 1 sent on none." and no error. | |
| 9 | `/reload`, then open `WTF\Account\<ACCOUNT>\SavedVariables\WarriorWorkshopProbe.lua` in a text editor. | The file exists and contains `WarriorWorkshopProbeDB = {` with `static`, `events`, `registrations` and so on. | |
| 10 | Run the **solo checks** and the **encounter test script** in `docs/PROBE_RESULTS.md`. | Done; both players' files collected. | |

M1 is complete once the files are pasted back and `docs/PROBE_RESULTS.md` is filled in.
