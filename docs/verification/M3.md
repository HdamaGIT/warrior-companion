# M3 verification: probe extension

**Goal:** the extended probe (version 2) loads in the Forever beta, every new command writes its results, and the saved file comes back before the beta closes on **21 October 2026**.
**Full procedure:** the "Beta run script" at the end of `docs/PROBE_RESULTS.md` (it also covers the M0, M1 and M2 checks). This checklist is the pass/fail summary.
**Prerequisite:** `WarriorWorkshopProbe` installed (junction per `docs/DEV_SETUP.md`), `/console scriptErrors 1`, two equipment sets created.

| # | Step | Expected result | Pass? |
|---|---|---|---|
| 1 | Log in with the probe enabled. | No Lua error popup. | |
| 2 | `/wwprobe help` | The command list includes `combat`, `spells`, `trainer`, `tank`, `chat`, `chatkey`, `sets`, `swapbtn`, `macro`, `status`. | |
| 3 | `/wwprobe` | Version/interface line; `issecretvalue: function` or `nil` (either is a finding). | |
| 4 | `/wwprobe spells` | `Spells dump saved: …` and, if any, a "Not resolved by name" list. | |
| 5 | `/wwprobe tank` | `Tank stats saved.` | |
| 6 | `/wwprobe macro` | `Macro test: create ok, edit ok, deleted. Limits: …`. No `WW Probe` macro is left in the macro window. | |
| 7 | `/wwprobe sets`, then `/wwprobe sets 1` out of combat | Sets are listed; then `n of n slots now match the set`. | |
| 8 | Bind "Probe: SAY test line (key press)" (Key Bindings → AddOns → Warrior Workshop Probe) and press it outdoors | The binding is listed; a `[WWPROBE test] … SAY key` line appears in /say. | |
| 9 | `/wwprobe chat` outdoors | One report line per channel after ~8s (sent/echoed/blocked). An "interface action failed" message is a finding, not a failure. | |
| 10 | `/wwprobe swapbtn <weapon link> [<off-hand link>]` out of combat | `Swap button ready on CTRL-SHIFT-F9`. | |
| 11 | `/wwprobe combat on`, then fight several mobs; press Ctrl-Shift-F9 and type `/wwprobe sets 2` mid-fight | No Lua errors during combat. Note whether the weapons and armour changed: ______ | |
| 12 | Open a trainer window | `Trainer dump saved (auto): n service(s).` | |
| 13 | `/wwprobe swapbtn restore`, then `/wwprobe status` | Combat samples > 0 in openWorld; `handler errors 0`. | |
| 14 | Log out to character select, log back in, `/wwprobe chatkey` | The key from step 8 is still bound. | |
| 15 | `/reload`, then find the saved file | `WTF\Account\<ACCOUNT>\SavedVariables\WarriorWorkshopProbe.lua` exists and contains `probeVersion = 2`. | |

**Paste back:** the whole `WarriorWorkshopProbe.lua` file (and the second player's, if you did the group part), the client folder name, any Lua error text, the answer to step 11, and your built-in notes (V-31). A non-zero `handler errors` count is a probe bug: paste it even if everything else looks fine.
