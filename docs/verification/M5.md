# M5 verification: combat core, must-have alerts and HUD

**Goal:** the combat companion runs in open-world combat with secret values treated as unknown. Battle Shout, Execute, Overpower, auto-attack and Charge alerts appear when expected and never otherwise. The HUD can be moved and tested, and on a dungeon boss everything suspends cleanly (SPEC_V2 §7.7, D-044, D-045, D-048).
**Prerequisite:** the M0 junction setup (`python tools/wowdev.py install`). Run `/console scriptErrors 1` first so any Lua error is shown.
**Characters:** Sphere (level 8) knows Battle Shout, Charge and Heroic Strike, so steps 1–11 work at level 8. Overpower is learned at level 12 and Execute at level 24 (Classic kit). If no character knows them, mark steps 12–13 "not testable yet"; their rules switch themselves off (step 2).
**What is not in M5:** no interrupt alert (R-11) or cooldown tracker (R-06): both are No-go (D-044). No floating PARRY/DODGE text (X-06, D-043): the avoidance detector runs but only shows up as debug lines (step 10). No Overpower stance hint (D-048).
